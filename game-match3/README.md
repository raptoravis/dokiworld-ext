# Match-3 V1 master

This directory is the immutable source-and-asset snapshot of
`frontend/public/games/game-match3` taken on 2026-07-31 before the PSD-faithful
Banquet Contract UI rebuild.

- The snapshot is outside `public/games`, so catalog generation will not expose
  it as a second game.
- `index.html`, `index.js`, `engine.js`, and all referenced PNG assets are
  included, so the version can be restored as a complete runnable game.
- To restore V1, copy this directory's runtime files back into
  `frontend/public/games/game-match3`, excluding this README and
  `SHA256SUMS.txt`.
